# 📚 Student Task Manager Project

A simple, interactive, and responsive web application designed to help students track and manage their daily tasks efficiently.

🚀 **Live Demo:** [Click here to view the live site](https://amogha1234-am.github.io/Student-Task-Manager-Project/)

---

## 🌟 Features

* ➕ **Add Tasks**: Quickly create new tasks with details.
* ✅ **Mark Complete**: Keep track of completed vs. pending tasks.
* 🗑️ **Delete Tasks**: Remove tasks you no longer need.
* 📱 **Responsive Design**: Works smoothly across desktop and mobile screens.

---

## 🛠️ Tech Stack

* **HTML5**: For structuring the web page.
* **CSS3**: For styling and layout design.
* **JavaScript**: For interactive logic and task management functions.
